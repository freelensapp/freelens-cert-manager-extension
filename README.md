# freelens-cert-manager-extension

Freelens extension for cert-manager: certificates, requests, issuers, ACME
orders and challenges, with renewal and approval.

This repository is being set up. The extension code is being moved here from
https://github.com/maifeeulasad/freelens-cert-manager, where it was
originally developed by Maifee Ul Asad, who maintains it here as well.
